# Lesson 5: Data Structures

Part of [CS50x](../cs50.md) · **Language:** C · **Topics:** linked lists, hash tables, trees, dynamic memory

## Inheritance
Simulates how blood types pass through three generations of a family. Each person is allocated in memory with links to their parents, alleles are inherited from the parents, and the whole family is freed recursively.
**Practiced:** structs with pointers, recursion, malloc and free, avoiding memory leaks.

## Speller
A spell checker that loads a dictionary of over 140,000 words into a hash table and checks every word in a text against it, built for speed and with no memory leaks.
**Practiced:** hash functions, hash tables of linked lists, memory management, performance tuning.
