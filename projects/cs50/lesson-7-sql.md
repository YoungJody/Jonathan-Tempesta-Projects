# Lesson 7: SQL

Part of [CS50x](../cs50.md) · **Language:** SQL (SQLite) · **Topics:** relational databases, queries, joins

## Songs
SQL queries against a database of top-streamed Spotify songs and their artists, plus a short written analysis of the listening data.
**Practiced:** SELECT, filtering, sorting, aggregate functions.

## Movies
Thirteen SQL queries against an IMDb-based database of movies, people, stars, directors, and ratings.
**Practiced:** joins across multiple tables, nested queries.

## Fiftyville
Solved a mystery using only SQL: queried a town's records (crime reports, witness interviews, ATM transactions, phone calls, flights, and security logs) to identify the thief, where they escaped to, and their accomplice.
**Practiced:** investigative querying, joins, working through a dataset step by step.
