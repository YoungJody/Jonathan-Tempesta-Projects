# Lesson 3: Algorithms

Part of [CS50x](../cs50.md) · **Language:** C · **Topics:** searching, sorting, running time, structs

## Sort
Timed three compiled sorting programs on sorted, reversed, and random inputs of different sizes to work out which one used selection sort, bubble sort, and merge sort.
**Practiced:** Big O reasoning, best and worst cases, empirical testing.

## Plurality
Runs a plurality election: tallies one vote per voter and prints the winner, or all tied winners.
**Practiced:** structs, arrays, linear search.

## Runoff
Runs a ranked-choice (instant-runoff) election: tallies first choices, eliminates the last-place candidates, and repeats until someone has a majority or the remaining candidates tie.
**Practiced:** 2D arrays, multi-step algorithm design, edge cases.
