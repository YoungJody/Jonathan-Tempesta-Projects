# Lesson 9: Flask

Part of [CS50x](../cs50.md) · **Languages:** Python, SQL, HTML · **Topics:** web apps, routes, sessions, databases

## Birthdays
A Flask web app that stores birthdays in a SQLite database and lists them, with a form to add new entries.
**Practiced:** routes, GET and POST requests, Jinja templates, SQL inserts and selects.

## Finance
A stock-trading web app where users register, look up real-time stock quotes, and buy and sell shares with virtual cash. It tracks each user's portfolio and transaction history.
**Practiced:** user accounts with hashed passwords, sessions, input validation, SQL-backed state, calling an external API.
